# Voorbeeldberichten

Deze map bevat voorbeeldberichten bij de VB-PUO-standaard, per release een eigen map.

- **Niet normatief.** Een voorbeeld laat zien hoe een bericht eruit kan zien. Bij verschil gelden de
  JSON-schema's in de berichtmappen en de handleiding.
- **Main is leidend.** Voorbeelden kunnen tussen twee releases worden verbeterd of aangevuld, zonder nieuwe
  release van de standaard. Een tag bevat de voorbeelden zoals ze op dat moment waren; de actuele stand staat op
  main.
- **Elke wijziging staat in de `LEESMIJ.md` van de releasemap**, met datum, bestand en wat er is veranderd.

| map | hoort bij |
|---|---|
| `release-2027/` | release 2027 (v1.4.0) |

# Sample messages (English)

This folder contains sample messages for the VB-PUO standard, one folder per release.

- **Not normative.** A sample shows what a message can look like. In case of a difference, the JSON schemas in the
  message folders and the manual prevail.
- **Main is leading.** Samples can be improved or added between releases without a new release of the standard.
  A tag contains the samples as they were at that moment; the current state is on main.
- **Every change is listed in the `LEESMIJ.md` of the release folder**, with date, file and what changed.
